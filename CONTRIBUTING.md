# Contributing to qr-term

Thank you for your interest in contributing to `qr-term`!

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/authoritydmc/qr-term.git
   cd qr-term
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Build the project:**
   ```bash
   npm run build
   ```

4. **Run tests:**
   ```bash
   npm test
   ```

## Pull Request Guidelines

- Ensure tests pass with `npm test`.
- Keep changes focused and documented.
- For new terminal protocols or features, add corresponding unit tests in `src/test/`.
